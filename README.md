# 🕒 CSS + JS Analog Clock | ساعت آنالوگ با CSS و JS

A minimalist and elegant analog clock created using fundamental web technologies: HTML, CSS, and Vanilla JavaScript. This project demonstrates the power of CSS transforms and JavaScript's `Date` object to create dynamic, real-time applications.
---
  


## 🇮🇷 فارسی

یک ساعت آنالوگ ساده و زیبا که با استفاده از تکنولوژی‌های پایه وب یعنی HTML، CSS و جاوا اسکریپت خالص (Vanilla) ساخته شده است. این پروژه قدرت `transform` در CSS و کار با آبجکت `Date` در جاوا اسکریپت را برای ساخت اپلیکیشن‌های پویا و زنده نمایش می‌دهد.
---

## ✨ Features / ویژگی‌ها

### 🇬🇧 English
*   **Real-Time Movement:** The clock hands (hour, minute, and second) move smoothly and update every second to reflect the current time.
*   **Pure CSS Styling:** The clock face and hands are styled entirely with CSS, including the use of `transform-origin` to ensure correct rotation.
*   **Dynamic Calculation:** JavaScript's `Date` object is used to fetch the current time, and mathematical formulas convert this time into rotational degrees for each hand.
*   **Smooth Transitions:** A subtle CSS transition is applied to the hands to prevent jerky movements, especially when the second hand resets at the 60-second mark.
*   **Lightweight & Performant:** Built with zero dependencies, making it extremely fast and efficient.

### 🇮🇷 فارسی
*   **حرکت در زمان واقعی:** عقربه‌های ساعت (ساعت‌شمار، دقیقه‌شمار و ثانیه‌شمار) به نرمی حرکت کرده و هر ثانیه برای نمایش زمان دقیق به‌روزرسانی می‌شوند.
*   **طراحی کامل با CSS:** صفحه و عقربه‌های ساعت به طور کامل با CSS طراحی شده‌اند. از `transform-origin` برای اطمینان از چرخش صحیح عقربه‌ها از مرکز استفاده شده است.
*   **محاسبات پویا:** از آبجکت `Date` در جاوا اسکریپت برای گرفتن زمان فعلی استفاده شده و با فرمول‌های ریاضی، این زمان به درجه‌های چرخش برای هر عقربه تبدیل می‌شود.
*   **انیمیشن‌های نرم:** یک `transition` ظریف در CSS به عقربه‌ها اعمال شده تا از حرکات ناگهانی و پرشی، به خصوص در زمان بازگشت عقربه ثانیه‌شمار به نقطه شروع، جلوگیری شود.
*   **سبک و بهینه:** این پروژه بدون هیچ وابستگی خارجی (framework/library) ساخته شده و در نتیجه بسیار سریع و بهینه است.

## 🛠️ Technologies Used / تکنولوژی‌های استفاده شده

*   **HTML5**
*   **CSS3**
    *   `transform: rotate()`
    *   `transform-origin`
    *   `transition`
    *   Flexbox for centering
*   **Vanilla JavaScript (ES6+)**
    *   `new Date()` object and its methods (`getSeconds`, `getMinutes`, `getHours`)
    *   `setInterval()` for periodic execution
    *   DOM Manipulation (`querySelector`)
