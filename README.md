# 🕒 CSS + JS Analog & Digital Clock | ساعت آنالوگ و دیجیتال با CSS و JS

A minimalist and elegant clock project featuring both analog and digital clocks created using fundamental web technologies: HTML, CSS, and Vanilla JavaScript.  
This project demonstrates the power of CSS transforms, JavaScript's `Date` object, and DOM manipulation to create dynamic, real-time applications.

---

## 🇮🇷 فارسی

یک پروژه ساعت ساده و زیبا که شامل ساعت آنالوگ و دیجیتال است و با استفاده از تکنولوژی‌های پایه وب یعنی HTML، CSS و جاوا اسکریپت خالص (Vanilla) ساخته شده است.  
این پروژه قدرت `transform` در CSS، کار با آبجکت `Date` در جاوا اسکریپت و تغییرات داینامیک DOM را برای ساخت اپلیکیشن‌های پویا و زنده نمایش می‌دهد.

---

## ✨ Features / ویژگی‌ها

### 🇬🇧 English
* **Real-Time Movement:**  
  The analog clock hands (hour, minute, and second) move smoothly and update every second to reflect the current time.  
  The digital clock displays the current time in HH:MM:SS format and updates every second.
* **Pure CSS Styling:**  
  Both clocks are styled entirely with CSS. The analog clock uses `transform-origin` for correct rotation. The digital clock uses clean typography and responsive layout.
* **Dynamic Calculation:**  
  JavaScript's `Date` object fetches the current time, converting it into rotational degrees for analog hands and formatted strings for digital display.
* **Smooth Transitions:**  
  A subtle CSS transition prevents jerky movements in the analog clock hands.
* **Lightweight & Performant:**  
  Built with zero dependencies, making it extremely fast and efficient.

### 🇮🇷 فارسی
* **حرکت در زمان واقعی:**  
  عقربه‌های ساعت آنالوگ (ساعت‌شمار، دقیقه‌شمار و ثانیه‌شمار) به نرمی حرکت کرده و هر ثانیه به‌روزرسانی می‌شوند.  
  ساعت دیجیتال نیز زمان فعلی را به صورت ساعت:دقیقه:ثانیه نمایش داده و هر ثانیه به‌روزرسانی می‌شود.
* **طراحی کامل با CSS:**  
  هر دو ساعت کاملاً با CSS طراحی شده‌اند. ساعت آنالوگ از `transform-origin` برای چرخش دقیق استفاده می‌کند و ساعت دیجیتال از تایپوگرافی تمیز و چیدمان واکنش‌گرا بهره می‌برد.
* **محاسبات پویا:**  
  زمان فعلی با آبجکت `Date` گرفته شده و برای عقربه‌ها به درجه چرخش و برای ساعت دیجیتال به رشته‌های قالب‌بندی شده تبدیل می‌شود.
* **انیمیشن‌های نرم:**  
  یک `transition` ظریف در CSS از حرکت پرشی عقربه‌های ساعت آنالوگ جلوگیری می‌کند.
* **سبک و بهینه:**  
  بدون هیچ وابستگی خارجی (framework/library) ساخته شده و بسیار سریع و بهینه است.

## 🛠️ Technologies Used / تکنولوژی‌های استفاده شده

* **HTML5**
* **CSS3**  
  - `transform: rotate()`  
  - `transform-origin`  
  - `transition`  
  - Flexbox for centering  
* **Vanilla JavaScript (ES6+)**  
  - `new Date()` and methods (`getSeconds`, `getMinutes`, `getHours`)  
  - `setInterval()` for periodic updates  
  - DOM Manipulation (`querySelector`, `textContent`)
